# Employee Management API

A Spring Boot REST API for managing employees.

## Features

- JWT Authentication
- Role-Based Authorization
- Refresh Token
- Employee CRUD
- Pagination & Sorting
- Global Exception Handling
- AWS S3 Profile Image Upload
- AWS S3 Profile Image Delete
- AWS S3 Pre-signed URLs
- PostgreSQL
- Swagger/OpenAPI

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- AWS S3
- Maven
